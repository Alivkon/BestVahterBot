Список запрещённых слов перенесён в SQLite

Дата: 13.11.2026  |  Проект: BestVahterBot

Что изменено

  • В data/forbidden_words.sqlite3 создана таблица запрещённых слов с уникальным регистронезависимым ключом.
  • Начальный список загружается в базу однократно при первом запуске.
  • Слова, ранее сохранённые в data/extra_words.json, автоматически импортируются при первом запуске с базой.
  • Команда /add записывает новые слова прямо в SQLite; дубликаты отсекаются базой и нормализацией Unicode через casefold().
  • База размещена в data/, который уже подключён как постоянный Docker volume.

Проверки

  • py_compile для обоих Python-файлов — успешно.
  • Изолированный тест начальной загрузки, миграции JSON, добавления слов и отсева повторов без учёта регистра — успешно.
  • Рабочая SQLite-БД создана и проверена: 120 уникальных слов.
  • Полный запуск Telegram-бота и запросы к Telegram API не выполнялись.

Примечание: при развёртывании сохраните каталог data/. На существующем экземпляре JSON-слова переносятся в БД однократно; файл JSON после миграции не используется.
