# LLMs.md — правила работы для LLM-ассистентов над проектом BestVahterBot

## Обязательное правило: HTML-файл изменений после каждой правки

После **каждого шага с изменениями** кода или конфигурации проекта необходимо
создавать HTML-файл с описанием всех внесённых на этом шаге изменений.

Требования:

1. **Расположение:** `/opt/bots/BestVahterBot/changelog/`
2. **Имя файла:** `YYYY-MM-DD_<краткое-имя-шага>.html`
   (например: `2026-11-06_add-command.html`)
3. **Содержимое файла:**
   - дата и название шага;
   - перечень изменённых/созданных файлов и что именно в них изменилось;
   - суть изменений (новая функциональность, исправления, рефакторинг);
   - какие проверки были выполнены и их результаты;
   - примеры использования / примечания, если применимо.
4. Файл должен быть самодостаточным HTML со стилями (открываться в браузере
   без внешних зависимостей).
5. Один шаг (один запрос пользователя) = один HTML-файл. Внутри одного шага
   можно перечислять несколько изменений, сгруппировав их по файлам.
