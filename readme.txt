@BestVahterBot

Бот-модератор чата: удаляет сообщения с запрещёнными словами (bestvahterbot_words.py)
и уведомляет администратора. Запущен в Docker-контейнере.

КОМАНДЫ БОТА
------------
  /start — приветствие: возможности бота и число чатов, где он работает
           (бот запоминает чаты, из которых видит сообщения; список в data/chats.json)

  /add слово1, слово2, ... — ТОЛЬКО для администратора: добавить запрещённые слова.
           Слова разделяются запятыми, точками с запятой или переносами строк.
           Добавленные слова хранятся в data/extra_words.json и переживают перезапуск.
           Пример: /add продажа батов, накрутка подписчиков

СЕКРЕТЫ
-------
Секреты (токен бота, ID администратора) лежат в файле .env рядом с ботом.
Шаблон: .env.example. Файл .env не копировать в git и в образ!

После смены токена в .env перезапустить: docker compose up -d

ЗАПУСК / ПЕРЕЗАПУСК (docker compose)
------------------------------------
cd /opt/bots/BestVahterBot

  docker compose up -d            # запустить (или применить изменения .env/compose)
  docker compose up -d --build    # пересобрать образ и запустить (после правок кода)
  docker compose restart          # простой перезапуск контейнера
  docker compose stop             # остановить
  docker compose down             # остановить и удалить контейнер/сеть

ЛОГИ И СТАТУС
-------------
  docker compose logs -f bestvahter-bot   # смотреть логи (Ctrl+C для выхода)
  docker compose logs --tail 50           # последние 50 строк
  docker ps --filter name=bestvahter_bot  # статус контейнера

АВТОЗАПУСК
----------
Контейнер создан с restart: always — при перезагрузке сервера бот стартует
сам вместе со службой Docker, а при падении автоматически перезапускается.
Ничего дополнительно делать не нужно.

Ручной запуск без Docker (не рекомендуется, для отладки):
  cd /opt/bots/BestVahterBot
  ~/miniconda3/envs/telegram_bot_env/bin/python bestvahterbot.py
